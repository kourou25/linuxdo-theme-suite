# 伙伴动作资产

## 内容

- `hero-001`、`hero-003`～`hero-007`、`hero-009`～`hero-016`：
  640×640、四帧透明 APNG 伙伴成品，共 14 套。
- `hero-002` 为局部头像，`hero-008` 为纯装饰图标，不具备可见肢体，
  在发布包中继续使用静态 PNG。

每套动作均由角色可见的手臂、腿部、衣袖、头部、躯干或非人物附肢产生
姿态变化。长袍、抱枕、玩偶等原有遮挡关系保持不变，不补画原图中不可见
的身体部位，也不使用整图旋转、缩放、位移或上下浮动冒充肢体动作。

## 生成与复用

输入参考为各伙伴的静态版本。生图模型按每个角色可见身体结构生成透明
2×2 姿态帧，由 `scripts/build-hero-action-apng.py` 裁切并合成为
640×640 APNG。输出继续使用 `.png` 扩展名，保持现有素材包结构和拖拽逻辑。

发布包只包含 APNG 成品，不包含键控底图、透明动作分镜或其他处理文件。

## 验证状态

已通过数量、帧数、画布尺寸和逐帧四角透明度自动检查。
版本：1.0.0；更新时间：2026-07-29。
