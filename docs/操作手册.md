# LINUX DO Theme Suite v0.9.0 操作手册

## 1. 产品说明

LINUX DO Theme Suite 是仅在当前浏览器本地生效的 LINUX DO 油猴主题工具，适用于 `https://linux.do/*`。

主要功能：

- 41 套常规主题，覆盖浅色、暗色、动漫、摄影、国风与场景风格；
- 支持可用主题的视频背景，并可随时关闭动态效果；
- “抽取你的 L 站英雄”：随机组合 16 套背景与透明伙伴；
- 背景强度、刷新轮播和正文文字颜色自定义；
- 可拖动的悬浮入口，以及点击页面空白处或按 `Esc` 自动收起的工具面板；
- 图片、视频和英雄素材只保存在当前浏览器的 IndexedDB 中，不上传到网站。

## 3. 首次安装

### 3.1 安装浏览器扩展

安装 Tampermonkey 或 Violentmonkey。使用 Tampermonkey 时，如果页面顶部提示“请启用允许用户脚本”，请在浏览器扩展详情页打开“允许用户脚本”。

### 3.2 安装脚本

1. 打开油猴扩展管理面板。
2. 点击“添加新脚本”或右上角 `+`。
3. 删除编辑器中的示例内容。
4. 用文本编辑器打开 `linuxdo-theme-suite-v0.9.0-full.user.js`。
5. 复制全部内容并粘贴到油猴编辑器。
6. 按 `Ctrl + S` 保存，确认脚本处于启用状态。
7. 确认扩展允许在 `linux.do` 读取和更改网站数据。
8. 打开或刷新 `https://linux.do/`。

### 3.3 导入统一素材包

1. 解压 `linuxdo-theme-suite-v0.9.0-suite-pack.zip`。
2. 不要移动或单独选择解压目录中的文件；保留 `manifest.json`、`images/`、`videos/`、`backgrounds/` 和 `companions/` 的目录结构。
3. 在 LINUX DO 页面点击主题工具悬浮按钮。
4. 点击“导入统一素材包”。
5. 在目录选择器中选择刚才解压得到的整个文件夹。
6. 等待面板显示导入成功。

ZIP 文件不能直接导入，必须先解压再选择目录。统一素材包只需导入一次，不再分别导入常规壁纸包和英雄包。

导入完成后保持当前常规主题，不会自动抽取英雄。需要随机英雄时，再点击“抽取英雄”“只换背景”或“只换伙伴”。

## 4. 更新版本

### 4.1 更新脚本

1. 打开油猴扩展管理面板。
2. 打开现有 `LINUX DO Theme Suite` 脚本的编辑页面。
3. 删除旧内容。
4. 将新版 `linuxdo-theme-suite-v0.9.0-full.user.js` 全部内容粘贴进去。
5. 按 `Ctrl + S` 保存并刷新 LINUX DO。

### 4.2 更新素材

脚本更新不会自动替换浏览器中已导入的旧素材。新版包含新增、删除或重新补景的图片时，按以下步骤更新：

1. 打开主题工具。
2. 点击“清除本地素材”。
3. 解压新版统一素材包。
4. 点击“导入统一素材包”，选择新版解压目录。
5. 导入成功后刷新页面一次。

清除本地素材只删除本浏览器内由主题工具导入的图片、视频和英雄资源，不会删除账号、帖子、消息或服务器数据。

## 5. 功能使用

### 5.1 切换常规主题

打开主题工具后，点击主题列表中的任意主题。常规主题会立即接管背景，并自动关闭当前随机英雄覆盖层，避免两套背景互相冲突。

本版宽屏素材统一使用连续横向场景和 `cover` 填充，不再使用“模糊底图 + 原图前景”的重复叠加方式。

### 5.2 抽取你的 L 站英雄

- “抽取英雄”：背景和伙伴从同一编号随机资源中同时更换；
- “只换背景”：保留当前伙伴，只随机更换背景；
- “只换伙伴”：保留当前背景，只随机更换伙伴。

英雄使用匿名编号，界面不显示名称或手动选择器。抽取英雄前会自动暂停常规图片或视频媒体层；重新点击常规主题即可退出英雄背景。

### 5.3 背景强度

“背景强度”同时调节：

- 背景图可见程度；
- 内容区、评论区和个人中心面板透明度；
- 页面渐隐遮罩；
- 毛玻璃模糊强度。

强度较高时，启用“自定义文字颜色”：浅色背景使用深色文字，暗色背景使用浅色文字。

### 5.4 动态背景

“动态背景”开启且当前主题存在视频素材时播放视频；关闭后使用静态海报。

以下情况会自动使用静态背景或暂停播放：

- 系统开启“减少动态效果”；
- 浏览器标签页进入后台；
- 当前主题没有视频素材；
- “动态背景”开关处于关闭状态。

脚本会在视频结束、暂停或短暂卡顿时尝试恢复播放，并为已知尾部黑帧素材提前回环。

### 5.5 刷新切换主题

开启“刷新切换主题”后，每次完整刷新页面会按主题列表前进一套。该功能只轮播常规主题，不自动抽取英雄。

### 5.6 自定义文字颜色

1. 打开“自定义文字颜色”开关。
2. 点击颜色选择器。
3. 选择适合当前背景的正文颜色。

设置会覆盖页面正文、导航和次要文字颜色。主题工具面板使用独立的高对比度颜色，不受该设置影响。

### 5.7 移动悬浮按钮

按住主题工具悬浮按钮并拖动，可将其移动到视口内其他位置。松开后位置自动保存在当前浏览器。

- 短按：打开或关闭主题工具；
- 拖动：移动悬浮按钮；
- 点击页面其他位置：自动收起工具面板；
- 按 `Esc`：收起工具面板；
- 点击面板右上角 `×`：收起工具面板。

窗口尺寸变化后，按钮会自动限制在可见区域内，不会永久停留在浏览器边界外。

## 6. 常见问题

### 6.1 点击主题但背景没有变化

1. 确认已导入新版统一素材包。
2. 点击一次目标常规主题；此操作会关闭随机英雄覆盖层。
3. 若仍无变化，点击“清除本地素材”，重新导入新版统一素材包。
4. 完整刷新页面。

旧版分别导入的素材可能仍保存在 IndexedDB 中。更新到 v0.9.0 后，执行一次“清除本地素材 → 导入统一素材包”。

### 6.2 左右出现留白或重复人物

确认脚本和素材包都是 v0.9.0。旧版素材使用过完整人物前景与填充背景双层方案，会产生重复或左右不自然。v0.9.0 已改用连续横向补景图。

### 6.3 动态背景只播放一次

1. 确认“动态背景”已开启。
2. 确认系统未启用“减少动态效果”。
3. 切换到其他主题后再切回。
4. 若问题持续，重新导入统一素材包并刷新页面。

### 6.4 页面文字看不清

降低背景强度，或开启“自定义文字颜色”并选择对比度更高的颜色。暗色主题使用浅色文字，浅色主题使用深色文字。

### 6.5 工具面板遮挡内容

先收起面板，再拖动悬浮按钮到页面另一侧。面板会根据按钮位置自动选择上方、下方、左侧或右侧的可见空间。

## 7. 暂停与卸载

### 7.1 暂时停用

1. 打开油猴扩展菜单或管理面板。
2. 关闭 `LINUX DO Theme Suite` 的启用开关。
3. 刷新 LINUX DO。

### 7.2 完整卸载

1. 在主题工具中点击“清除本地素材”。
2. 打开 Tampermonkey 或 Violentmonkey 管理面板。
3. 找到 `LINUX DO Theme Suite`。
4. 点击删除并确认。
5. 刷新 LINUX DO。

如果删除脚本前忘记清除素材，可在浏览器的站点设置中清除 `linux.do` 的站点数据。
